# oud.duinvelt.nl

De vorige website van Duinvelt Installatietechniek, zoals hij tot 24-11-2026 op
duinvelt.nl stond. Hij blijft hier staan om te vergelijken met de nieuwe site.
Dat bedrijf bestaat niet: New Story gebruikt het als proefomgeving voor AI.
Medewerkers, klanten en projecten zijn fictief.

De inhoud is `site/` uit de bronrepo van Duinvelt, commit 875cf77 van
22-10-2026 (op duinvelt.nl gepubliceerd als af39c32 in duinvelt/website).
Alleen `CNAME` en dit bestand zijn anders.
